## Peglord (browser game)

Open `peglord/index.html` in a browser (no build step, no audio files; every sound is made with the Web Audio API). Drop balls through the pegs to bank XP, spend 99 XP per level on three heroes, gear them up and fight through ten stages to The Landlord. All rules and balance numbers live in `peglord/js/data.js`.
